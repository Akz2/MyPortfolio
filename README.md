# Aniket's Portfolio

This repository contains the source code for my professional portfolio, including both the frontend and backend.

## Structure

- `aniket-portfolio-frontend/`: Next.js application for the user interface.
- `aniket-portfolio-backend/`: Node.js/Express application for the API and data management.

## Getting Started

### Frontend
1. Navigate to `aniket-portfolio-frontend/`
2. Run `npm install`
3. Run `npm run dev`

### Backend
1. Navigate to `aniket-portfolio-backend/`
2. Run `npm install`
3. Run `npm start`

## Deployment

- Frontend is deployed on Vercel.
- Backend is deployed on Render/Railway.
